# 新型RTT测量系统 部署与测试指南

> **语言**：C++17 | **平台**：Linux (Ubuntu 20.04 LTS) | **构建**：CMake 3.15+

---

## 1. 环境准备

### 1.1 硬件要求

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 双核 x86_64 | 四核及以上 |
| 内存 | 4 GB | 16 GB+ |
| 磁盘 | 10 GB | 50 GB+ SSD |
| 操作系统 | Ubuntu 18.04+ | Ubuntu 20.04 LTS |

### 1.2 安装系统依赖

```bash
# 基础编译工具
sudo apt-get update
sudo apt-get install -y build-essential cmake g++ gdb

# 必需库
sudo apt-get install -y libpcap-dev zlib1g-dev

# 可选：DPDK在线抓包
sudo apt-get install -y dpdk dpdk-dev

# 可选：tcptrace基准对比工具
sudo apt-get install -y tcptrace

# 可选：性能分析工具
sudo apt-get install -y linux-tools-common perf valgrind
```

### 1.3 验证安装

```bash
g++ --version      # 应 ≥ 9.0
cmake --version    # 应 ≥ 3.15
pcap-config --version
tcptrace -v        # 可选
```

## 2. 编译构建

### 2.1 获取代码

```bash
# 假设项目代码在工程实践目录
cd ~
# 创建C++项目目录
mkdir -p rtt_measurement
# 将include/ src/ tests/ CMakeLists.txt 放入该目录
```

### 2.2 CMake构建

```bash
cd rtt_measurement
mkdir build && cd build

# Release构建
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j$(nproc)

# Debug构建（带调试符号和更多检查）
cmake .. -DCMAKE_BUILD_TYPE=Debug -DENABLE_SANITIZERS=ON
make -j$(nproc)

# 带DPDK支持
cmake .. -DUSE_DPDK=ON
make -j$(nproc)
```

### 2.3 编译产物

```
build/
├── librtt_core.a          # 核心静态库
├── rtt_measure            # 主可执行文件
├── test_cuckoo_hash       # 单元测试
├── test_flow_table
├── test_packet_table
└── test_rtt_engine
```

## 3. 运行

### 3.1 基本用法

```bash
# 查看帮助
./rtt_measure --help

# 离线模式：处理pcap文件
./rtt_measure -i ../data/smallFlows.pcap -o ./output

# 指定PT大小
./rtt_measure -i trace.pcap --pt-max-size 8192 -o ./output_small_pt

# 启用自适应PT
./rtt_measure -i trace.pcap --adaptive-pt -o ./output_adaptive

# 启用ML异常检测
./rtt_measure -i trace.pcap --ml-model ../models/iforest.onnx
```

### 3.2 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-i <file>` | 输入pcap文件路径 | 必填（离线模式） |
| `-o <dir>` | 输出目录 | `./output` |
| `--ft-max-size <n>` | 流表最大条目数 | 262144 |
| `--pt-max-size <n>` | 包表最大条目数 | 262144 |
| `--ft-stages <n>` | 流表流水线级数 | 4 |
| `--pt-stages <n>` | 包表流水线级数 | 4 |
| `--recirc <n>` | 再循环次数 | 3 |
| `--syn-action <mode>` | SYN处理: ignore/timeout/staging | ignore |
| `--adaptive-pt` | 启用自适应PT管理器 | false |
| `--enable-aft` | 启用近似流表 | false |
| `--dpdk` | 使用DPDK在线模式 | false |
| `--interface <if>` | DPDK网卡名称 | eth0 |
| `--ml-model <path>` | ONNX异常检测模型路径 | 无 |

```bash
    ./rtt_measure -i smallFlows.pcap -o valgrind_output 2>&1 | tee valgrind.log

```

## 6. 故障排除

### 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| `cannot open pcap file` | 文件路径错误或权限不足 | `ls -l <file>` 检查 |
| `undefined reference to pcap_*` | libpcap未链接 | `sudo apt install libpcap-dev` |
| `std::bad_alloc` | 内存不足 | 减小 `--ft-max-size` 或 `--pt-max-size` |
| `Segmentation fault` | 空指针或越界 | 用gdb调试: `gdb --args ./rtt_measure -i ...` |
| 编译错误 `c++17 required` | GCC版本过低 | `sudo apt install g++-9` 或用 devtoolset |
| DPDK初始化失败 | 大页内存未配置 | `echo 1024 > /sys/kernel/mm/hugepages/hugepages-2048kB/nr_hugepages` |

### 调试建议

```bash
# Debug模式编译（含AddressSanitizer）
cmake .. -DCMAKE_BUILD_TYPE=Debug -DENABLE_SANITIZERS=ON

# GDB调试
gdb --args ./rtt_measure -i trace.pcap
(gdb) run
(gdb) bt     # 崩溃时查看调用栈

# 查看详细日志
./rtt_measure -i trace.pcap -v 3    # verbosity level 0-3
```
