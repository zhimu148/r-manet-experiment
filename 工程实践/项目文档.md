## 1. 项目概述

### 1.1 项目背景

往返时间（Round-Trip Time，RTT）是衡量计算机网络性能的核心指标之一，直接影响终端用户的服务质量体验（QoE）。RTT的精确测量对于网络拥塞控制、流量调度、安全检测（如BGP拦截攻击检测）等应用至关重要。

传统RTT测量分为两类：主动探测法（发送ICMP Ping包，无法测量应用级真实RTT）和被动监控法（如tcptrace仅测量TCP握手，对长连接覆盖不足，握手RTT仅占全部RTT的约13%）。

高速可编程交换机（Intel Tofino系列）的出现为内联实时RTT测量提供了独特机会。但由于TCP协议复杂性（序列号回绕、重传、乱序）和硬件资源严格限制（有限SRAM、流水线级数），设计这样一个系统充满挑战。本课题基于SIGCOMM 2022论文提出的Dart原型系统，使用**C/C++在Linux环境下**开发新型RTT测量系统。

### 1.2 项目目标

1. **深入理解Dart系统**：研读论文与开源代码，掌握核心设计原理
2. **C++系统设计与实现**：使用C/C++在Linux上实现完整的RTT测量系统
3. **实验验证与评估**：使用真实网络流量数据验证系统功能与性能
4. **改进方案设计**：在Dart基础上提出并实现改进方案
5. **完整文档输出**：编写项目设计文档、API文档、部署测试指南

## 2. 背景与动机

### 2.1 RTT测量的重要性

- **传输层性能**：TCP拥塞控制算法（CUBIC、BBR）依赖RTT估计调整发送速率
- **应用层QoE**：HTTP/3(QUIC)、视频流媒体、实时通信等对延迟高度敏感
- **网络安全**：RTT异常突变可能指示BGP劫持等流量拦截攻击

### 2.2 现有RTT测量方法的局限性

| 方法 | 优点 | 缺点 |
|------|------|------|
| 主动探测 (ICMP Ping) | 实现简单 | 测量探测包RTT，不是真实流量RTT；消耗带宽 |
| 被动握手 (tcptrace) | 不注入额外流量 | 仅从TCP握手获取RTT（仅占13%）；长连接无法覆盖 |
| **Dart + 本系统** | 内联实时；覆盖所有TCP包；可在交换机内部实时反应 | 需要可编程交换机硬件；受硬件资源约束 |

### 2.3 C++实现的优势

选用C/C++在Linux上实现本系统的理由：

- **高性能**：零拷贝包解析、内存池管理，优于解释型语言
- **系统级集成**：可直接调用libpcap、DPDK、eBPF等Linux内核接口
- **低延迟**：没有GC停顿，适合实时RTT测量场景
- **可移植性**：C++17标准代码可在不同Linux发行版间移植
- **符合课程要求**：满足老师指定的C/C++ + Linux开发工具要求


### 3.2 核心概念：测量范围 (MR)

对每个TCP流，维护区间 `[left_edge, right_edge)`：

- **left_edge**：最小未确认字节的序列号
- **right_edge**：最大期望确认的序列号（= 最新SEQ + payload_size）

**SEQ方向**（数据发出）：扩展MR → 向PT记录发送时间戳
**ACK方向**（确认返回）：收缩MR → 匹配PT记录 → 计算 RTT = t_ack − t_send

### 3.3 三大核心数据结构

| 数据结构 | C++类名 | 作用 | 键类型 | 实现 |
|----------|---------|------|--------|------|
| Flow Table | `FlowTable` | 维护每流MR状态 | `FlowKey` (五元组) | `CuckooHashTable<FlowKey, FlowRecord, 4>` |
| Packet Table | `PacketTable` | 存储飞行中包的时间戳 | `PacketKey` (流键+eACK) | `CuckooHashTable<PacketKey, PacketRecord, 4>` |
| Approx. Flow Table | `ApproxFlowTable` | 加速PT过期淘汰 | `FlowKey` | `CuckooHashTable<FlowKey, FlowRecord, 4>` |

### 3.4 数据流转过程

```
SEQ方向（发送方→接收方的数据包）:
  TCP Data Pkt → classify_packet() → FlowTable::process_seq()
    → MR扩展/重置 → FlowTable插入/更新
    → 标记need_pt_insert → PacketTable::insert_with_check()
    → 存入时间戳

ACK方向（接收方→发送方的确认包）:
  TCP ACK Pkt → classify_packet() → FlowTable::process_ack()
    → MR收缩 → 标记need_pt_lookup
    → PacketTable::match_and_compute_rtt()
    → 找到匹配: RTT = t_now - t_send → 触发RttCallback
    → 记录折叠: 删除FlowRecord
```

## 4. 核心数据结构与算法

### 4.1 多级Cuckoo哈希表（C++模板实现）

Flow Table和Packet Table均基于多级Cuckoo哈希表，使用C++模板实现：

```cpp
template <typename KeyType, typename ValueType, size_t NumStages = 4>
class CuckooHashTable {
    // 使用CRC32哈希链为每条记录在每级计算独立索引
    u32 compute_stage_index(const KeyType& key, size_t stage) const;
    
    // 插入时若目标位置被占用，则"踢出"旧记录（Cuckoo行为）
    bool insert(const ValueType& record, Timestamp now,
                std::vector<ValueType>* touched = nullptr);
    
    // 被踢出的记录尝试插入下一级
    // 所有级均失败 → 触发再循环 → 仍失败 → 保留旧记录，丢弃新记录
};
```

### 4.2 插入算法（C++实现）

```cpp
template <typename K, typename V, size_t N>
bool CuckooHashTable<K, V, N>::insert(
    const V& record, Timestamp now, std::vector<V>* touched) 
{
    accountant_.record_insert_attempt();
    accountant_.create_snapshot(now);
    
    size_t attempts = 0;
    size_t stage = 0;
    size_t recirculations = 0;
    V current_record = record;
    size_t original_index = compute_stage_index(record.key, 0) % stage_size_;
    
    while (attempts < (config_.recirculations + 1) * N) {
        if (attempts > 0 && stage == 0) {
            recirculations++;
            accountant_.record_recirculation();
        }
        
        // 根据eviction_stage配置决定何时检查淘汰
        if (should_evict_at_current_stage(stage)) {
            if (check_eviction_condition(current_record, now, nullptr)) {
                accountant_.record_insert_success();
                return true;
            }
        }
        
        u32 index = compute_stage_index(current_record.key, stage) % stage_size_;
        V* evicted = insert_at_stage(stage, index, &current_record);
        
        if (evicted == nullptr) {
            accountant_.record_insert_success();
            return true;  // 插入到空位
        }
        
        if (stage == 0 && touched != nullptr) {
            touched->push_back(*evicted);
        }
        
        current_record = *evicted;  // Cuckoo! 被踢出的继续找位置
        stage = (stage + 1) % N;
        attempts++;
    }
    
    // 表满且无法淘汰: 重新插入旧记录，丢弃新记录（防止大RTT偏差）
    accountant_.record_insert_failure();
    insert_at_stage(0, original_index, &current_record);
    return false;
}
```

### 4.3 流表配置参数

```cpp
struct FlowTableConfig {
    size_t    max_size         = 262144;   // 最大条目数 (256K)
    size_t    num_stages       = 4;        // 流水线级数
    u32       recirculations   = 3;        // 再循环次数
    bool      prefer_new       = true;     // 优先保留新记录
    EvictionStage eviction_stage = EvictionStage::START;
    u32       entry_timeout_ms = 10000;    // 超时(ms)
    SynAction syn_action       = SynAction::IGNORE;  // SYN处理
    double    sampling_rate    = 1.0;      // 采样率
};
```

### 4.4 关键设计决策

**1. SYN包忽略策略**：握手RTT仅占全部RTT的~13%，忽略SYN可节省大量表空间。

**2. 防止大RTT偏差**：表满时保留旧记录、丢弃新记录，而非相反。
```cpp
// 所有再循环均失败后：
// ❌ 错误做法：丢弃旧记录（导致长RTT的流被系统性遗漏）
// ✅ 正确做法：重新插入旧记录，丢弃新记录
insert_at_stage(0, original_index, &evicted_by_new_record);
```

**3. 淘汰条件优先级**：
1. 超时 → 无条件淘汰
2. AFT检查（eACK ≤ 已确认字节）→ 快速淘汰
3. FT检查（流不存在或ACK已被确认）→ 淘汰

### 5.3 公共类型定义（common.h）

```cpp
// include/rtt_core/common.h
#pragma once

#include <cstdint>
#include <chrono>
#include <string>
#include <vector>
#include <array>

namespace rtt {

// ===== 基本类型别名 =====
using u8  = uint8_t;
using u16 = uint16_t;
using u32 = uint32_t;
using u64 = uint64_t;

// ===== IPv4地址 =====
struct Ipv4Addr {
    u8 octets[4];
    Ipv4Addr() : octets{0,0,0,0} {}
    Ipv4Addr(u8 a, u8 b, u8 c, u8 d) : octets{a,b,c,d} {}
    explicit Ipv4Addr(u32 addr);
    u32 to_u32() const;
    bool operator==(const Ipv4Addr& o) const { return memcmp(octets, o.octets, 4) == 0; }
    std::string to_string() const;
};

// ===== 流键：TCP五元组 =====
struct FlowKey {
    Ipv4Addr src_ip, dst_ip;
    u16 src_port, dst_port;
    bool operator==(const FlowKey& o) const;
    std::string to_hash_string() const;  // 用于CRC32哈希
};

// ===== 包键：流键 + 期望确认号 =====
struct PacketKey {
    FlowKey flow_key;
    u32 exp_ack;
    bool operator==(const PacketKey& o) const;
};

// ===== 测量范围(MR) =====
struct MeasurementRange {
    u32 left_edge;   // 最小未确认字节
    u32 right_edge;  // 最大期望确认
    bool is_collapsed() const { return left_edge == right_edge; }
};

// ===== 时间戳 =====
using Timestamp = std::chrono::steady_clock::time_point;
inline double to_ms(const Timestamp& t1, const Timestamp& t2) {
    return std::chrono::duration<double, std::milli>(t1 - t2).count();
}

// ===== 流签名 (CRC32哈希) =====
using FlowSignature = u32;
FlowSignature compute_seq_flow_sign(const FlowKey& key);
FlowSignature compute_ack_flow_sign(const FlowKey& key);

// ===== 记录类型 =====
struct FlowRecord {
    FlowKey key;
    FlowSignature flow_sign;
    MeasurementRange mr;
    Timestamp entry_time, update_time;
    u8 entry_flags, update_flags;
};

struct PacketRecord {
    PacketKey key;
    Timestamp send_time;
    u32 sequence_number;
};

struct RttSample {
    FlowKey flow_key;
    u32 sequence_number;
    double rtt_ms;
    Timestamp timestamp;
};

// ===== 枚举 =====
enum class EvictionCode : u8 {
    SUCCESS = 0, TIMEOUT = 1, AFT_CHECK_FAIL = 2,
    FT_NOT_FOUND = 3, FT_CHECK_FAIL = 4, INSERT_FAILED = 5
};

enum class SynAction : u8 { IGNORE = 0, TIMEOUT = 1, STAGING = 2 };
enum class EvictionStage : u8 { START = 0, IMMEDIATE = 1, END = 2 };

} // namespace rtt
```

### 5.4 RTTEngine 主控制器

```cpp
// include/rtt_core/rtt_engine.h
namespace rtt {

class RTTEngine {
public:
    struct Config {
        FlowTable::FlowConfig   flow;
        PacketTable::Config     packet;
        ApproxFlowTable::Config aft;
        bool enable_aft = false;
        bool enable_adaptive_pt = false;
        std::string home_subnet_file;  // 本地子网配置
    };

    using RttCallback = std::function<void(const RttSample&)>;

    explicit RTTEngine(const Config& config);
    
    /** 处理单个TCP包——主入口 */
    void process_packet(Ipv4Addr src_ip, Ipv4Addr dst_ip,
                        u16 src_port, u16 dst_port,
                        u32 seq_no, u32 ack_no,
                        u8 flags, u32 payload_size,
                        Timestamp timestamp);

    /** 注册实时RTT回调（每检测到一个RTT触发） */
    void set_rtt_callback(RttCallback cb);
    
    /** 获取统计数据 */
    size_t total_rtt_samples() const;
    const std::vector<RttSample>& rtt_samples() const;
    const FlowTable& flow_table() const;
    const PacketTable& packet_table() const;
    
    /** 保存统计结果到文件 */
    void save_statistics(const std::string& output_dir) const;

private:
    PacketType classify_packet(Ipv4Addr src, Ipv4Addr dst,
                               u8 flags, u32 payload) const;
    bool is_home_network(Ipv4Addr ip) const;
    void handle_seq_direction(const FlowKey& key, u32 seq_no,
                              u32 payload, u8 flags, Timestamp ts);
    void handle_ack_direction(const FlowKey& key, u32 ack_no,
                              u8 flags, Timestamp ts);

    Config config_;
    FlowTable      flow_table_;
    PacketTable    packet_table_;
    std::unique_ptr<ApproxFlowTable> aft_;
    std::vector<Ipv4Addr> home_subnets_;
    std::vector<RttSample> rtt_samples_;
    RttCallback rtt_callback_;
};

} // namespace rtt
```

```cpp
    while ((opt = getopt(argc, argv, "i:o:h")) != -1) {
        switch (opt) {
            case 'i': input_file = optarg; break;
            case 'o': output_dir = optarg; break;
            case 'h':
                printf("Usage: %s -i <pcap_file> [-o output_dir]\n", argv[0]);
                return 0;
        }
    }
    
    if (input_file.empty()) {
        fprintf(stderr, "Error: -i <pcap_file> is required\n");
        return 1;
    }
    
    // 1. 配置RTT引擎
    rtt::RTTEngine::Config cfg;
    cfg.flow.max_size = 256 * 1024;
    cfg.flow.recirculations = 3;
    cfg.flow.syn_action = rtt::SynAction::IGNORE;
    cfg.packet.max_size = 256 * 1024;
    cfg.packet.recirculations = 3;
    
    rtt::RTTEngine engine(cfg);
    rtt::RttCollector collector;
    
    // 2. 注册RTT回调
    engine.set_rtt_callback([&collector](const rtt::RttSample& s) {
        collector.add_sample(s);
    });
    
    // 3. 读取pcap并逐包处理
    rtt::PcapReader reader(input_file);
    size_t packet_count = 0;
    
    reader.set_callback([&engine, &packet_count](
        const rtt::PcapReader::ParsedPacket& pkt) 
    {
        engine.process_packet(pkt.src_ip, pkt.dst_ip,
                              pkt.src_port, pkt.dst_port,
                              pkt.seq_no, pkt.ack_no,
                              pkt.tcp_flags, pkt.payload_size,
                              pkt.timestamp);
        packet_count++;
        
        if (packet_count % 1000000 == 0) {
            printf("Processed %zuM packets, %zu RTT samples\n",
                   packet_count / 1000000, engine.total_rtt_samples());
        }
    });
    
    printf("Starting packet processing...\n");
    auto t0 = std::chrono::steady_clock::now();
    reader.process_all();
    auto t1 = std::chrono::steady_clock::now();
    
    // 4. 输出统计
    double elapsed = std::chrono::duration<double>(t1 - t0).count();
    printf("Done. %zu packets in %.1fs (%.0f pkts/s)\n",
           packet_count, elapsed, packet_count / elapsed);
    printf("Total RTT samples: %zu\n", engine.total_rtt_samples());
    
    // 5. 保存结果
    engine.save_statistics(output_dir);
    auto stats = collector.compute_stats();
    printf("RTT stats: min=%.3f max=%.3f mean=%.3f median=%.3f ms\n",
           stats.min_ms, stats.max_ms, stats.mean_ms, stats.median_ms);
    
    rtt::StatsWriter writer(output_dir);
    writer.write_summary(stats);
    writer.write_samples(engine.rtt_samples());
    
    return 0;
}
```

## 9. 新型测量系统的改进设计

本章提出的改进方案均设计为使用**C/C++在Linux环境**下实现。

### 9.1 改进一：自适应PT大小调节（C++实现）

**实现文件**：`include/adaptive/pt_manager.h`, `src/adaptive/pt_manager.cpp`

```cpp
class AdaptivePTManager {
public:
    struct Config {
        double alpha = 0.2;              // EWMA平滑因子
        double low_threshold = 0.3;      // 低水位
        double high_threshold = 0.8;     // 高水位
        double min_sampling_rate = 0.1;
        double max_sampling_rate = 1.0;
    };

    void update_utilization(size_t num_records, size_t capacity);
    bool should_sample();               // 判断是否采样当前包
    double sampling_rate() const;       // 获取当前采样率
    double ewma_utilization() const;    // 获取EWMA利用率
};
```

自适应逻辑：EWMA利用率 > 80% → 采样率×0.8；利用率 < 30% → 采样率×1.2。

### 9.2 改进二：RTT异常检测（C++实现）

**实现文件**：`include/analysis/anomaly_detector.h`, `src/analysis/anomaly_detector.cpp`

```cpp
class AnomalyDetector {
public:
    enum class AnomalyType { SPIKE, DRIFT_UP, DRIFT_DOWN, JITTER };
    
    struct Anomaly {
        AnomalyType type;
        Timestamp detected_time;
        FlowKey flow_key;
        double current_rtt_ms, baseline_rtt_ms, deviation;
        std::string description;
    };

    using AlertCallback = std::function<void(const Anomaly&)>;
    
    void process_sample(const RttSample& sample);
    void set_alert_callback(AlertCallback cb);
};
```

特征：滑动窗口（50样本短窗口 + 500样本长窗口基线），尖峰阈值3×基线，抖动阈值5×标准差。可选ONNX Runtime加载预训练Isolation Forest模型。

### 9.3 改进三：QUIC协议支持（C实现）

QUIC使用UDP承载，Packet Number单调递增替代TCP序列号。Flow Key扩展增加Connection ID。解析QUIC短首部和长首部，适配QUIC ACK_MP帧。

### 9.4 改进四：多粒度RTT测量（C实现）

区分三种延迟：网络RTT（不含端点处理）、端点RTT（含协议栈延迟）、逐跳延迟（需配合INT获取）。

### 9.5 改进五：SRv6路径感知RTT（C实现）

扩展Flow Key增加Path ID（从SRH Segment List哈希），维护路径级RTT统计，支持SR Policy动态路径优化。

### 9.6 改进方案技术路线总结

| 改进方向 | 核心模块 | 语言 | Linux依赖 |
|----------|---------|------|-----------|
| 自适应PT调节 | `AdaptivePTManager` | C++ | std::atomic, chrono |
| ML异常检测 | `AnomalyDetector` | C++ | ONNX Runtime C API (可选) |
| QUIC支持 | `QuicParser` | C | lsquic / 自实现UDP解析 |
| 多粒度RTT | `LatencyDecomposer` | C | eBPF / INT对接 |
| SRv6路径感知 | `Srv6PathResolver` | C | DPDK + SRH解析 |
